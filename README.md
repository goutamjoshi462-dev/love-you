# For My Favorite Person ❤️

A romantic love sanctuary webpage with floating memory polaroids, morphy glass aesthetics, interactive love notes, and Pink Floyd's *Wish You Were Here*.

## ✨ Features
- 📸 **Floating Memory Backdrop**: All 36 photo memories drift gracefully across the screen in 3D multi-plane depth.
- 💌 **Surprise Message Flow**: Starts with an elegant floating glass pill; clicking **Open Message 💌** blossoms into the love sanctuary and starts playing the music.
- 🎸 **Soundtrack**: Pink Floyd - *Wish You Were Here* (1975).
- 💖 **Interactive Affection**: Kisses & hugs counter with heart bursts and soft chimes.
- 📜 **Handwritten Love Letter**: Wax-sealed parchment with an intimate heartfelt letter.
- 🎨 **Morphy Glass Design**: Ultra-translucent glassmorphism optimized for both desktop and mobile screens.
